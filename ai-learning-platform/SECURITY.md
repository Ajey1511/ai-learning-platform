# Security policy

Do not report vulnerabilities publicly. Contact the repository owner through a private security advisory or a private channel listed on the repository profile.

This academic prototype is not production-hardened. Before deployment, use HTTPS, configure a high-entropy secret outside source control, set restrictive CORS origins, provision admin accounts through a controlled process, review database backups and access, and perform a security review. Never submit real student credentials or personally identifying assessment data to public issues.
